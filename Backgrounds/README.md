# 🌄 Подборка фонов для LightLauncher

Размер окна лаунчера: **780 × 570 пикселей** (соотношение ~16:11.7).  
Все изображения масштабируются автоматически (`setScaledContents(True)`), сохраняя пропорции без искажений. Для интерфейса в стиле **Modern Glassmorphism** идеально подходят темные, сумеречные или контрастные фоны, где нижняя часть (примерно от 400px до 570px) затемнена для максимальной читаемости кнопок и полей ввода.

## 📌 Как установить выбранный фон в лаунчере:
1. Запустите LightLauncher.
2. Перейдите в **«⚙ Настройки»** -> вкладка **«🎮 Основные»**.
3. В строке **«Фон лаунчера»** нажмите кнопку **«📁 Выбрать...»**.
4. Выберите любой файл из папки `Backgrounds` (или укажите собственный файл `.png` / `.jpg`).
5. Нажмите **«✓ Сохранить»** — фон применится мгновенно без перезапуска!
